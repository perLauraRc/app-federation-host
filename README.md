# App Micro Frontends Host

This project is a host application for a micro-frontend architecture built with Vite, React 18, TypeScript, TailwindCSS 3, and other modern tools. It serves as the main entry point for integrating multiple micro-frontends.

## What is inside?

This project uses the following tools and libraries:

- [Vite](https://vitejs.dev) - Fast build tool for modern web applications
- [ReactJS](https://reactjs.org) - A JavaScript library for building user interfaces
- [TypeScript](https://www.typescriptlang.org) - A strongly typed programming language for JavaScript
- [TailwindCSS](https://tailwindcss.com) - A utility-first CSS framework
- [Vitest](https://vitest.dev) - A blazing fast unit test framework
- [Testing Library](https://testing-library.com) - Tools for testing React components
- [Eslint](https://eslint.org) - A tool for identifying and fixing problems in JavaScript code
- [Prettier](https://prettier.io) - An opinionated code formatter

## Getting Started

### Install

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/perLauraRc/app-federation-host.git
cd app-federation-host
```

Install dependencies:

```bash
npm install
```

Serve the application with hot reload at <http://localhost:5173>:

```bash
npm run dev
```

### Lint

Run the linter to check for code quality issues:

```bash
npm run lint
```

### Typecheck

Check for TypeScript type errors:

```bash
npm run typecheck
```

### Build

Build the application for production:

```bash
npm run build
```

### Test

Run unit tests:

```bash
npm run test
```

View and interact with your tests via the UI:

```bash
npm run test:ui
```
